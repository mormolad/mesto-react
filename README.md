# Техническое задание: Геймификация интерфейса студента (MVP → v2.0)

## 1. Общая концепция

**Цель**: Превратить обучающий тренажёр из инструментальной панели в полноценный игровой опыт с элементами RPG, где студент проходит путь от «стажёра» до «инженера-наладчика» через выполнение заданий, сбор инструментария и отработку навыков диагностики.

**Ключевые игровые механики** (по фреймворку Octalysis ):
- **Core Drive 2**: Развитие и достижение (уровни, навыки, прогресс-бары)
- **Core Drive 3**: Творчество и обратная связь (свободная тренировка, эксперименты с неисправностями)
- **Core Drive 5**: Социальное влияние (рейтинги, сравнение с группой)
- **Core Drive 7**: Непредсказуемость и любопытство (случайные задания, «пасхалки» в интерфейсе)

## 2. Дашборд студента (главный экран)

### 2.1. Визуальная концепция
**Игровая метафора**: Кабинет дежурного инженера — персональное рабочее пространство, которое «прокачивается» по мере обучения.

| Элемент | Текущее состояние (MVP) | Требуемое состояние (v2.0) |
|---------|------------------------|---------------------------|
| **Фон** | Статичное фото кабинета | Интерактивная сцена с анимацией (часы тикают, монитор мерцает, за окном меняется время суток) |
| **Дверь** | Переход в навигацию | Анимированная дверь с индикатором «выход на объект». При наведении — звук скрипа, при клике — анимация открытия + переход |
| **Шкаф СИЗ** | Статичный элемент | Инвентарь с анимацией открытия. Предметы «затемнены» до получения. При наведении — tooltip с описанием и условием разблокировки |
| **Инструментальный ящик** | Статичный элемент | Прогресс-бар заполненности. Новые инструменты добавляются после заданий. Клик — 3D-вид инструментов с возможностью «осмотра» |
| **Монитор** | Чёрный экран | «Живой» экран ПТК с мини-виджетами: текущее задание, статистика, уведомления |
| **Телефон** | Иконка с восклицательным знаком | Анимация звонка при новом задании. История звонков — архив заданий |
| **Документация** | Не представлена | Стопка документов/планшет на столе. Клик — библиотека с разделами: ПТК, КРУЗА-П, Схемы, Инструкции |

### 2.2. Игровые элементы дашборда

**Система уровней**:
```
Уровень 1: Стажёр (0-100 XP)
  └─ Доступно: базовые задания, 3 СИЗ, мультиметр
Уровень 2: Младший наладчик (100-300 XP)
  └─ Доступно: задвижки с двойной блокировкой, осциллограф, КРУЗА-П
Уровень 3: Наладчик (300-600 XP)
  └─ Доступно: сложные каскадные неисправности, тепловизор, генератор сигналов
Уровень 4: Инженер-наладчик (600-1000 XP)
  └─ Доступно: все типы неисправностей, «ночные смены» (ограниченное время)
Уровень 5: Ведущий инженер (1000+ XP)
  └─ Доступно: режим преподавателя (постановка заданий другим), кастомные сценарии
```

**Источники XP**:
- Выполнение задания: 20-50 XP (зависит от сложности)
- Идеальное выполнение (без подсказок, с первой попытки): +50% XP
- Обнаружение скрытой неисправности: +10 XP
- Изучение документации (первое прочтение раздела): +5 XP
- Ежедневный вход: +5 XP (стрик: +1 XP за каждый день подряд, макс +15)

## 3. Навигация (глобальный доступ)

### 3.1. Единый паттерн навигации
Доступ к навигации с **любой страницы** тренажёра:

| Страница | Триггер навигации | Визуальная метафора |
|----------|-------------------|---------------------|
| **Дашборд** | Дверь | Физическая дверь кабинета, ведущая на «производственную площадку» |
| **ПТК / КРУЗА-П** | Кнопка «Выход» в хедере + иконка «Карта объекта» | Кнопка аварийного выхода + мини-карта цеха в углу экрана |
| **Схема / Диагностика** | Иконка «Навигация» в тулбаре | GPS-иконка в инженерном планшете |
| **Документация** | Хлебные крошки + кнопка «К кабинету» | Стрелка «назад» в стиле промышленной маркировки |
| **Задвижка (визуал)** | Кнопка «Смена объекта» | Переключатель режимов на пульте управления |

### 3.2. Визуализация навигации (на основе вашей схемы)

**Центральный узел**: АРМ Инженера (кабинет студента)
**Спутники**:
- **ПТК** — серверная стойка (доступна с 1-го уровня)
- **Кабинет 1** — дополнительное рабочее место (для групповых заданий, уровень 3+)
- **Задвижка** — 3D-модель/фото реального оборудования (доступна с 1-го уровня)
- **КРУЗА-П** — панель управления (доступна с 2-го уровня)

**Геймификация навигации**:
- Недоступные локации отображаются «под замком» с требованием уровня
- При наведении на локацию — звуковой эффект (гул оборудования) и краткое описание
- Переход между локациями анимирован: «перемещение» по коридору цеха (2-3 сек)

## 4. Система заданий (квесты)

### 4.1. Типы заданий

| Тип | Описание | Награда |
|-----|----------|---------|
| **Сюжетное** | Линейная цепочка от простого к сложному. Пример: «Найдите обрыв в цепи управления задвижкой №3» | XP + новый инструмент + разблокировка локации |
| **Ежедневное** | Случайная неисправность, генерируемая ежедневно. Время выполнения: 10-15 мин | XP ×2 + бонусный СИЗ (косметический) |
| **Экстренное** (случайное) | Всплывающее уведомление: «Аварийная ситуация! Задвижка заклинило!» — ограниченное время на реакцию | XP ×3 + ачивка |
| **Свободная тренировка** | Студент сам выбирает неисправность из доступных | XP (уменьшенные) + прогресс в статистике |
| **Экзаменационное** | Преподаватель запускает, ограниченное время, без подсказок | Сертификат уровня + крупный бонус XP |

### 4.2. UI задания на дашборде

**Виджет «Текущее задание»** на мониторе дашборда:
- Название + номер (как «наряд-допуск»)
- Прогресс-бар (этапы: получение задания → подготовка СИЗ → диагностика → устранение → отчёт)
- Таймер (для ограниченных по времени)
- Кнопка «Приступить» (переход к тренажёру)
- Кнопка «Отложить» (доступно 1 раз в сутки)

## 5. Инвентарь: СИЗ и инструменты

### 5.1. Система предметов

**СИЗ** (средства индивидуальной защиты):
- Каска (уровень 1, косметическая)
- Защитные очки (уровень 1, функциональные: без них нельзя работать с электрощитами)
- Перчатки диэлектрические (уровень 2, обязательны для КРУЗА-П)
- Спецодежда «Профи» (уровень 3, косметическая + 5% бонус XP)
- Респиратор (уровень 4, для работы в «загазованных» сценариях)

**Инструменты**:
- Мультиметр (уровень 1, 3 режима: U/I/R)
- Отвёртка-индикатор (уровень 1)
- Осциллограф (уровень 2, диагностика пульсаций в цепях управления)
- Тепловизор (уровень 3, обнаружение перегрева контактов)
- Клещи токоизмерительные (уровень 3)
- Генератор сигналов (уровень 4, имитация датчиков)

### 5.2. Механика использования

- **Автоматическая экипировка**: При входе в локацию система проверяет необходимый СИЗ. Если не надет — предупреждение, при игнорировании — штраф XP и «травма» (кулдаун 5 мин)
- **Выбор инструмента**: Drag-and-drop на объект диагностики или клик + автоприменение
- **Износ инструментов** (опционально для v2.1): После N использований требуется «поверка» (мини-игра: калибровка прибора)

## 6. Статистика и достижения

### 6.1. Профиль студента

**Вкладки**:
1. **Общая статистика**:
   - Время в тренажёре
   - Количество найденных/пропущенных неисправностей
   - Среднее время диагностики
   - Точность (% правильных действий с первой попытки)
   
2. **Навыки** (радарная диаграмма):
   - Электробезопасность
   - Чтение схем
   - Работа с ПТК
   - Работа с КРУЗА-П
   - Диагностика механических неисправностей
   - Диагностика электрических неисправностей

3. **Достижения (ачивки)**:
   - «Первый шаг» — выполнено 1 задание
   - «Детектив» — нашёл скрытую неисправность
   - «На износ» — 100 использований мультиметра
   - «Без единой царапины» — 10 идеальных заданий подряд
   - «Ночная смена» — 5 заданий после 22:00 (если отслеживаем)
   - «Наставник» — помог одногруппнику (для уровня 5)

4. **История**:
   - Лента выполненных заданий с возможностью повторного прохождения
   - «Досье неисправностей» — каталог встреченных поломок с описанием

### 6.2. Лидерборд (опционально для MVP)

- **Групповой**: Рейтинг внутри группы преподавателя (топ по XP, топ по точности, топ по скорости)
- **Личный**: Сравнение с собой вчера (график прогресса)

## 7. Подсказки и обучение (геймификация помощи)

### 7.1. Система «Наставник»

Вместо сухих текстовых подсказок — персонаж-наставник (аватар старшего инженера):

| Ситуация | Реакция наставника |
|----------|-------------------|
| Студент долго бездействует (2 мин) | «Эй, молодой! Проверь питание — всегда начинай с автомата!» |
| Неправильная последовательность действий | «Стой! Сначала разрешение от КТЦ, потом манипуляции! Хочешь аварию?» |
| Повторная ошибка того же типа | «Ты уже наступал на эти грабли в задании №5. Вспомни: концевой выключатель...» |
| Идеальное выполнение | «Отличная работа! Как у меня в молодости. Вот тебе совет на будущее...» |

### 7.2. Штрафы и «последствия»

- **Аварийная ситуация**: При нарушении техники безопасности — экран «затемняется», звуковой сигнал, сообщение «Технологическая защита сработала!», сброс прогресса задания, потеря 10 XP
- «Травма» (без СИЗ): Кулдаун 5 мин, невозможность входа в локации
- «Перегрузка»: При 3 авариях подряд — принудительный перерыв 15 мин (игровой сон в кабинете)

### 8.3. Генератор заданий (Backend)

**Алгоритм ежедневного задания**:
```python
def generate_daily_quest(user_level: int) -> Quest:
    available_faults = FAULT_TYPES_BY_LEVEL[user_level]
    fault = random.choice(available_faults)
    
    # Вариации сложности
    modifiers = []
    if user_level >= 3:
        modifiers.append(random.choice(['TIME_LIMIT', 'HIDDEN_FAULT', 'CASCADE']))
    
    return Quest(
        type='DAILY',
        fault_type=fault,
        modifiers=modifiers,
        xp_reward=calculate_xp(fault, modifiers),
        time_limit=900 if 'TIME_LIMIT' in modifiers else None
    )
```

   - Футер: кнопки «Приступить» / «Отложить»

5. **Экран достижения** (всплывающий, 500×200):
   - Иконка ачивки (анимированная)
   - Название + описание
   - Звёздная пыль / конфетти (лёгкая анимация)

6. **Аватар наставника** (200×200, всплывающий из-за края):
   - 5 вариантов эмоций: нейтральная, довольная, строгая, удивлённая, поощряющая
   - Пузырь с текстом

### 9.3. Адаптивность

- **Desktop** (1920×1080): Полная сцена, все элементы видны
- **Laptop** (1366×768): Компактный режим, инвентарь в выпадающей панели
- **Tablet** (1024×768): Вертикальная ориентация, дашборд как «комната» с прокруткой
- **Мобильный** (опционально): Упрощённый интерфейс, список заданий + быстрые действия

## 10. Требования к QA

### 10.1. Функциональное тестирование

**Модуль «Прогрессия»**:
- [ ] Начисление XP за разные типы действий
- [ ] Корректный расчёт бонусов (идеальное выполнение, стрик)
- [ ] Повышение уровня при достижении порога
- [ ] Блокировка локаций до достижения уровня
- [ ] Блокировка заданий без необходимого СИЗ

**Модуль «Инвентарь»**:
- [ ] Получение предмета после задания
- [ ] Экипировка/снятие СИЗ
- [ ] Проверка обязательных СИЗ при входе в локацию
- [ ] Штраф за вход без СИЗ

**Модуль «Задания»**:
- [ ] Генерация ежедневного задания
- [ ] Таймеры и автозавершение по истечении времени
- [ ] Сохранение прогресса при перезагрузке страницы
- [ ] Корректный расчёт статистики (время, ошибки, подсказки)

**Модуль «Навигация»**:
- [ ] Доступ с любой страницы
- [ ] Корректные переходы между всеми локациями
- [ ] Сохранение состояния предыдущей локации

### 10.2. Нагрузочное тестирование

- [ ] 50 студентов одновременно — получение ежедневных заданий
- [ ] WebSockets: стабильность при массовой рассылке ачивок

### 10.3. UX-тестирование

- [ ] Понятность интерфейса без инструкции (тест с новыми пользователями)
- [ ] Время поиска текущего задания на дашборде (< 5 сек)
- [ ] Понимание системы уровней (интервью после 30 мин использования)
