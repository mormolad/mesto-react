# 📱 Приложение-помощник для турагента: Структура функционала

---

## 🗂️ МОДУЛЬ 1: Поиск и работа с турами
| Фича | Описание | Приоритет |
|------|----------|-----------|
| **Умный поиск** | Фильтры по бюджету, стране, датам, типу отдыха, питанию | 🔴 Высокий |
| **Профиль предпочтений клиента** | Сохранение параметров: «любит море», «без детей», «все включено» | 🔴 Высокий |
| **Сравнение отелей** | Таблица: рейтинг, цена, удобства, отзывы, фото | 🟡 Средний |
| **Трекер цен** | Уведомление при снижении цены на сохранённый тур | 🟡 Средний |
| **Агрегатор «горящих»** | Сбор предложений от нескольких ТО в одном интерфейсе | 🔴 Высокий |
| **Быстрый экспорт** | Подборка → PDF / ссылка / текст для мессенджера | 🟡 Средний |

## 📱 МОДУЛЬ 2: SMM и контент-инструменты
| Фича | Описание | Приоритет |
|------|----------|-----------|

| **Медиа-банк** | Хранение фото/видео отелей, логотипов, бренд-элементов | 🟡 Средний |

## 🗃️ МОДУЛЬ 3: База знаний («Вики» турагента)
| Фича | Описание | Приоритет |
|------|----------|-----------|

## 👥 МОДУЛЬ 4: Мини-CRM (работа с клиентами)
| Фича | Описание | Приоритет |
|------|----------|-----------|
| **Карточка клиента** | Контакты, история поездок, предпочтения, даты, документы | 🔴 Высокий |
| **Сегментация** | Теги: «семьи», «luxury», «горящие», «визовые» для таргет-рассылок | 🟡 Средний |
| **Трекер сделок** | Воронка: запрос → подборка → бронь → оплата → пост-продажа | 🔴 Высокий |
| **Авто-триггеры** | Напоминания: «не ответил 3 дня», «за 30 дней до вылета», «после возвращения» | 🟡 Средний |
| **История коммуникаций** | Лог переписки из Telegram/WhatsApp в карточке клиента | 🟡 Средний |

## 🚀 Дорожная карта MVP (фокус на быстрый результат)

```
Этап 1 (0-30 дней):
✅ Карточка отеля с тегами + быстрый поиск
✅ Шаблоны сторис/постов (5-10 базовых)
✅ Мини-профиль клиента (контакты + предпочтения)
✅ Чек-лист «Вопросы перед подбором»

Этап 2 (30-60 дней):
✅ Трекер сделок (воронка)
✅ Визовый справочник (базовый)
✅ Авто-напоминания (2-3 триггера)
✅ Экспорт подборки в PDF/текст

Этап 3 (60-90 дней):
✅ Агрегатор горящих туров
✅ Генератор контента
✅ Калькулятор маржи
✅ Интеграция с Telegram-ботом
```

## 📊 Матрица приоритетов: «Польза / Сложность»

```
Высокая польза + Низкая сложность → ДЕЛАТЬ СРАЗУ:
• Карточка отеля с тегами
• Шаблоны сторис
• Профиль клиента
• Чек-листы

Высокая польза + Высокая сложность → ПЛАНИРОВАТЬ:
• Агрегатор горящих туров
• Авто-триггеры
• Калькулятор маржи

Низкая польза + Низкая сложность → ДОБАВИТЬ ПОЗЖЕ:
• Глоссарий
• Реферальная система
• Медиа-банк

Низкая польза + Высокая сложность → ОТЛОЖИТЬ:
• API для внешних интеграций
• Продвинутая аналитика
• Авто-заполнение форм ТО
```

---

> 💡 **Рекомендация**: Начните с Модулей 1+2+3 (база отелей + контент + вики) — это даст мгновенную экономию времени и повысит качество подборок. Модуль 4 (мини-CRM) подключайте, когда появится поток повторных клиентов.
