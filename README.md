| Технологии | TypeScript, Next.js, NestJS, PostgreSQL, Redis |

## ⚠️ ФАКТОРЫ, ВЛИЯЮЩИЕ НА СРОКИ

### Положительные (могут сократить сроки на 10-20%)

| Фактор | Влияние |
|--------|---------|
| Использование shadcn/ui готовых компонентов | -3-5 дней на этап |
| Prisma вместо ручных SQL-запросов | -5-7 дней на этап 1 |
| Vercel для деплоя фронтенда (упрощает DevOps) | -5 дней на этап 0 |
| ChatGPT/Copilot для boilerplate кода | -10-15% общего времени |

### Отрицательные (могут увеличить сроки на 20-40%)

| Риск | Вероятность | Доп. время |
|------|-------------|------------|
| **API туроператоров** — нестабильность, изменения форматов | Высокая | +10-15 дней |
| **2FA и безопасность** — сложности с cookies, CORS | Средняя | +3-5 дней |
| **PDF генерация через Puppeteer** — memory leaks, баги | Средняя | +5-7 дней |
| **Drag-n-drop на мобильных** — touch-события | Средняя | +2-3 дня |
| **Голосовые заметки** — Web Speech API ограничения | Низкая | +2-3 дня |
| **Баги после деплоя** — dev/prod расхождения | Высокая | +10-15% |
